# Exact fibre-LYM certificate: d=3, k=2, n=5

Write `P=[0,3]^5`.  For each pair of coordinates `S` and each assignment
`z` to the other three coordinates, `F(S,z)` is a copy of `[0,3]^2`.
If `B` is 2-separated, then `B∩F(S,z)` is an antichain.  The rank sizes of
`[0,3]^2` are

```
a = (1,2,3,4,3,2,1).
```

Hence the LYM inequality on a fibre is
`sum_{x in B∩F} 1/a_{rk_S(x)} <= 1`.

For an outside type `z=(z_0,z_1,z_2,z_3)` (the counts of values 0,1,2,3
among the three fixed coordinates), assign the following nonnegative weight
`lambda(z)` to every fibre having that type:

```
(0,0,0,3)  1/10       (0,0,1,2)  2/15       (0,0,2,1) 17/90
(0,0,3,0) 1117/3240    (0,1,0,2) 13/90       (0,1,1,1) 2503/9720
(0,1,2,0)  559/1620    (0,2,0,1) 79/270       (0,2,1,0) 893/2430
(0,3,0,0)   14/45      (1,0,0,2) 167/540      (1,0,1,1) 1123/3240
(1,0,2,0) 1313/4860    (1,1,0,1) 169/540       (1,1,1,0) 907/3240
(1,2,0,0)  17/90       (2,0,0,1)  3/20        (2,0,1,0)  59/360
(2,1,0,0)   2/15       (3,0,0,0)  1/10.
```

For a global type `t=(t_0,...,t_3)`, the coefficient of a vertex of that
type in the weighted sum of all fibre LYM inequalities is

```
C(t) = sum_{u<=t, |u|=2} lambda(t-u) * prod_i binom(t_i,u_i) / a_{sum i*u_i}.
```

Direct exact rational arithmetic gives `C(t)>=1` for every one of the 56
types `|t|=5`; the minimum is exactly 1.  The total right-hand side is

```
binom(5,2) * sum_z (3! / prod_i z_i!) lambda(z) = 161.
```

Therefore `|B| <= 161`, which is the size of the conjectured residue family
(`rk(x) in {0,7,14}`).  All 20 lambda values are strictly positive.

## Equality and uniqueness

If `|B|=161`, every individual fibre LYM inequality is an equality (all
weights are positive).  Exhaustive enumeration of antichains in `[0,3]^2`
shows the only antichains with LYM sum 1 are the seven complete rank levels
(ranks 0 through 6).  Thus each pair-fibre section of `B` is a complete local
rank level.

Consequently, whenever `x in B` and coordinates `i,j` are changed while
preserving `x_i+x_j`, the resulting point remains in `B`; this is because
the corresponding pair fibre is exactly one rank level.  The graph on
`[0,3]^5` generated by such two-coordinate transfers is connected on every
global rank level (a standard transfer argument: repeatedly move units from
coordinates above/below the target while staying in `[0,3]`).  Hence `B` is a
union of complete global rank levels.

Finally, in a pair fibre with outside rank `q`, the selected local rank must
be the unique `r in {0,...,6}` satisfying `q+r ≡ 7 (mod 7)`, since the global
rank-level union is 2-separated and has cardinality 161.  Therefore the
selected global ranks are exactly `0,7,14`; `B` is the conjectured family.
